# StageShow kit subset

Source: https://github.com/benjitaylor/skills/tree/299140fafd08df55a9c234e610c3f64af3f45531/stageshow

MIT-licensed kit modules used by the homepage workbench and their transitive dependencies. The scene begins with the `examples/form-error` composition. Unused device, brand, chart, and gallery modules are omitted. No third-party brand assets are included. See LICENSE and NOTICE.md.

Added for the GEPA weight-editing article (`src/components/wsp`), copied unchanged from the same pinned commit: `kit/code.tsx` and `code.css` (code lines with numbers), and `kit/parts/Meter.tsx` and `Meter.css` (a filling usage bar). Meter uses only the kit's own `reduced-motion.ts`; Code has no kit dependencies.
